## Чё я вообще сделал и зачем?

Я создал свои зеркала для популярных Github и Gitlab подписок для обхода белых списков в России.

Это было необходимо, потому что обычные Github и Gitlab подписки не умеют обновляться в VPN клиентах по типу V2rayNG или Happ, когда включены белые списки. В таких ситуациях приходится либо включать другой VPN, либо искать общественный WIFI, чтобы подключиться к нему и всё обновить. Моё зеркало же решает данную проблему: если вы добавите моё зеркало вместо оригинальной подписки, то вы сможете обновить подписку всегда, вне зависимости от того, включены у вас белые списки или нет.

Внимание: если в районе вашего местоположения произойдёт шатдаун по каким-либо причинам, то у вас не будет работать даже моё зеркало, так как у вас отвалится весь интернет. В таких случаях у вас не будет работать даже яндекс и даже наш богоподобный и МАКСимально скрепный и АНАЛогов_нет-ный мессенджер МАКС.

## Кратко о том, как я это сделал

1. Я создал этот репозиторий на Bitbucket, так как стабильно способ работает только с помощью Bitbucket.
2. Затем я достал RAW ссылку для подписки из своего репозитория на Bitbucket и добавил её в ссылку Яндекс переводчика по этому шаблону: https://translate.yandex.ru/translate?url=ПОДПИСКА&lang=de-de

Подробнее способ создания зеркала Yandex+Bitbucket описывается у одного из разработчиков своих Github подписок для обхода белых списков - igarek. [Ссылка на способ](https://github.com/igareck/vpn-configs-for-russia#---%D0%B7%D0%B5%D1%80%D0%BA%D0%B0%D0%BB%D0%B0--)

Примечание: вы хоть и можете в теории подставить в этот шаблон ссылку из Github, например, но спустя 1-2 суток она у вас сломается и перестанет обновляться. Ничего не сломается, только если вставить ссылку из Bitbucket, что я уже сделал за вас, вставив RAW ссылки подписок уже из этого репозитория.
